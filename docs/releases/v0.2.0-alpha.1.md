# ARGUS intelligence v0.2.0-alpha.1 candidate

This candidate extends the accepted YouTube Forensics evidence core with the first
ARGUS intelligence contract. It is not a release tag until the exact commit passes
GitHub CI and the release workflow.

## Added

- `intelligence`: consumes one or more verified evidence packages and emits a
  deterministic, separately hash-bound `argus.intelligence/v1` artifact.
- Platform-rule assessment, observed reach signals, document-frequency hashtag
  intelligence and explicit unknown engagement fields.
- `feedback`: appends observed performance as `argus.performance-feedback/v1`
  without changing evidence or the original recommendation.
- Hermes skill guidance for the evidence → intelligence → feedback chain.

## Boundaries

- Source evidence stays immutable and must verify before analysis.
- Intelligence is interpretation, never source evidence or publishing authority.
- Missing metrics are unknown; they are not estimated.
- No account credential, paid provider, social publishing or live scheduler is added.
- The existing `youtube-forensics` command and v0.1 evidence workflow remain
  compatible.
