# YouTube Forensics v0.1.0-alpha.1

First hardened alpha of the provider-neutral evidence layer extracted from the
Estate's ASTRO/ATOM video-forensics work.

## What it does

- Collects bounded public YouTube metadata, captions and comments without
  browser cookies.
- Optionally downloads permitted media and decodes every video frame.
- Retains cited visual state changes instead of producing an untraceable
  summary.
- Produces a hash-bound receipt that fails closed on missing, changed,
  unexpected, traversed or symlinked artifacts.
- Resumes an interrupted frame pass from validated durable checkpoints without
  duplicate frame-index entries; unrelated artifacts still fail closed.
- Installs as a Python CLI and includes a provider-neutral Hermes skill.

## Qualification

- The cross-platform local suite, Ruff and packaging checks pass before tag.
- The release workflow reruns tests and lint on the exact tag, checks that the
  tag commit belongs to `main`, and publishes only its checksummed build output.
- The owner verifies the final `main` matrix and CodeQL checks before creating
  the tag.
- Clean-wheel install, synthetic video analysis and receipt verification pass.

## Important limits

This is an alpha evidence collector, not a hidden-source extractor or automatic
copying system. Captions, OCR and comments remain untrusted evidence. YouTube
availability and rate limits vary. Download only media you are permitted to
download. Human or agent interpretation and independent implementation remain
separate steps. Receipts detect unregenerated changes; they are not signatures
or proof of authorship.
